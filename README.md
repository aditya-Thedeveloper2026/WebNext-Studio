# Webnest Studio

A modern, responsive website for **Webnest Studio** — a full-service digital solutions agency focused on helping businesses build a strong digital presence through creative design and reliable web solutions.

## Overview

Webnest Studio is designed to present the agency's services, showcase its work, communicate its pricing, and make it easy for potential clients to get in touch.

The website features a clean, premium interface with responsive layouts and interactive elements to deliver a smooth experience across desktop, tablet, and mobile devices.

## Features

- Modern, premium website design
- Fully responsive layout
- Mobile navigation menu
- Services and project showcase sections
- Pricing packages
- About and agency information
- Interactive FAQ section
- Contact form with email draft functionality
- Smooth scrolling navigation
- Scroll reveal animations
- Active navigation highlighting
- Back-to-top button
- Dynamic footer year

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Browser Support

Designed for modern browsers, including:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari
